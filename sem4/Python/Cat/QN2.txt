my_dict = {'a': 1, 'b': 2, 'c': 3}

b) {'a': 1, 'b': 2, 'c': 3}

9. What is the correct way to create a multiline string in Python?
a) my_string = "Line 1\nLine 2\nLine 3"
b) my_string = "Line 1, Line 2, Line 3"
c) my_string = """Line 1\nLine 2\nLine 3"""
d) my_string = 'Line 1\nLine 2\nLine 3'

10. Which of the following is the correct syntax to format a string using the format() method in
Python?
a) "{} {}".format(arg1, arg2)
b) format("{} {}", arg1, arg2)
c) "{} {}".format(arg1)(arg2)
d) format("{} {}", (arg1, arg2))

ANS: a) "{} {}".format(arg1, arg2)
